# Little Desk — Mini E-Commerce App

Project 05. HTML, CSS and vanilla JavaScript.

## Run locally
Extract and open index.html in a modern browser. No installation or build needed. Google Fonts requires internet; the store logic and inline SVG illustrations work without external APIs.

## Requirements covered
- Product cards dynamically rendered from an array of JavaScript objects
- Add to bag, quantity controls, remove items and item count
- Line totals, subtotal and total calculated from integer prices in paise
- Modal checkout preview with item quantities and total

## Additional features
Category filters, price sorting, responsive layout, empty-cart state, accessible dialog controls and LocalStorage cart persistence.

## Files
index.html: page and dialogs
style.css: responsive layout and product styling
app.js: product data, inline SVG illustrations, rendering, cart state and event listeners
